# 多屏车机 Monkey 压测

## 任务 ID

MONKEY-MULTISCREEN-001

## 当前状态

VERIFYING

## 目标与非目标

- 目标：浏览车机各屏，选择参与屏幕后以固定种子逐动作随机选屏。每屏可按包名选择白名单或黑名单，并配置系统区域。提供按屏事件记录和整机报告。
- 非目标：扩大到全局系统按键或车辆控制。

## 工作范围

Monkey 前端、后端任务与记录、Android 定向输入执行器、Windows 便携包和验收。基线 v1.0.2，保留本地实车 DBC。

## 逐文件审计台账

无

## 前置依赖

本地构建和测试环境，支持多屏的已授权 Android 设备。实车随机和耐久需驻车台架及可记录输入的测试界面。

## 阶段计划

- [x] S1 输入：Android 路由及屏幕信息。输出：发现、框选和配置接口。完成条件：主副屏身份可校验。恢复：屏幕配置与 API 测试。
- [x] S2 输入：逐屏配置。输出：设备端调度、日志与报告。完成条件：保留原生模式，安全地执行或拒绝动作。恢复：Android 执行器与 Monkey 生命周期。
- [ ] S3 输入：可运行功能。输出：自动、路由和耐久结果。完成条件：对应验收有实证。恢复：未覆盖屏幕和未执行的时长。
