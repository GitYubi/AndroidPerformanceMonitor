## V11 Windows x64 原生验证待办

待可用的干净 Windows x64 测试机或虚拟机。只执行通用便携包测试。Android 模拟器证据见 [S5](s5.md#android-模拟器-v10)；ZLG 和共享 CAN 的验收见 [S7](s7.md)。

1. 将本候选 ZIP 和仓库 [smoke.py](../../tools/windows/smoke.py) 放在测试目录。运行下列 PowerShell 命令并保存操作系统、ZIP 校验和退出输出。
2. 确认 Start.cmd 原生自检运行随包 Python、Node、ADB 和 Sharp。烟测核对含空格和中文路径、端口回退、同源 API、重复启动和退出。
3. 证据写入任务 V11。通过后勾选 S8，任务与索引同步为 COMPLETED，重跑任务校验。

```powershell
$zip = (Resolve-Path .\AndroidCarMonitor-Windows-x64-CODE-REMEDIATION-001.zip).Path
$smoke = (Resolve-Path .\smoke.py).Path
Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, BuildNumber, OSArchitecture
if ((Get-FileHash $zip -Algorithm SHA256).Hash -ne "e47c116a22e3329d87079d85bdbca46599fb49b03829a6218f941738b8ae7acb") {
  throw "整改候选包 SHA-256 不匹配"
}
$checkDir = Join-Path $env:TEMP ("便携整改 " + [guid]::NewGuid().ToString("N"))
Expand-Archive -LiteralPath $zip -DestinationPath $checkDir
Push-Location (Join-Path $checkDir "AndroidCarMonitor")
try {
  cmd.exe /d /c "Start.cmd --check"
  if ($LASTEXITCODE -ne 0) { throw "原生自检失败 $LASTEXITCODE" }
  & .\runtime\python\python.exe -X utf8 $smoke $zip
  if ($LASTEXITCODE -ne 0) { throw "原生烟测失败 $LASTEXITCODE" }
} finally {
  Pop-Location
}
```
